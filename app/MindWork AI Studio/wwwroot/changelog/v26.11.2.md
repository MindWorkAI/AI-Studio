# v26.11.2, build 261 (2026-11-xx xx:xx UTC)
- Added the BeyondFacts Lab as a prototype. It helps researchers prepare step by step for a challenging appearance, such as a panel discussion, an interview, or a hearing. An introduction explains how to work with the lab, and a chat tells you whether the lab fits your task. Each event gets a preparation of its own, which leads you through seven steps, from the details of the event to what you take away, and shows you which key details are still missing. In each step, a chat guides you with questions, based on your details and a guide on science in public debates. You can add material which every step takes into account, such as papers, the recording of an interview, or a poster. Your preparations are part of your data backups. To try it, open the app settings, allow preview features down to prototype, and enable the BeyondFacts Lab. Thanks to Lara Wüster from the Technical University of Munich (TUM) for the concept and the content of the lab.
- Added Lucide icons to assistant plugins: name an icon as `lucide:` followed by its name on lucide.dev, such as `lucide:house`. The names of MudBlazor icons keep working, so existing plugins need no change.
- Added a way to compress a long chat: with the new button in the chat toolbar, the AI summarizes the conversation, your documents included, and AI Studio continues it in a new chat with the summary, your last message, and the last answer of the AI. You name the new chat and can tell the AI what the summary should focus on. Since the new chat is much shorter, each further message costs fewer tokens. Your original chat stays as it is. Thanks, Jens Erler (`j-erler`), for this contribution.
- Added the choice whether AI Studio addresses you formally or informally, in languages which have both forms, such as German with "Sie" and "du". You find the option "Form of address" in the app settings, right below the language. The chats of the BeyondFacts Lab address you the same way.
- Added the form of address to configuration plugins, so that organizations can preset or lock whether AI Studio addresses their users formally or informally.
- Added the option for organizations to disable categories of assistants, such as entertainment, through configuration plugins. Assistant plugins which an organization deployed itself stay available.
- Added custom categories to assistant plugins: a plugin which fits none of the categories of AI Studio can name its own. AI Studio shows these names as the plugin writes them, in every language.
- Added the Model Comparison assistant, which shows you which of two models helps you better. You compare them blindly, without knowing which model wrote which answer: with the same request sent to both, or while you work on your own tasks over days or weeks. Charts show you which model wins, and a judge model can give you a second opinion based on your own expectations. You find the assistant in the category "General". Thanks, Dominic Neuburg (`donework`), for this contribution.
- Added the minimum confidence of the provider for each AI task, such as the data source selection or the security audit of assistant plugins, to configuration plugins, so that organizations can preset or lock it.
- Added the settings of the text content cleaner to configuration plugins, so that organizations can preset or lock which model cleans web content.
- Added the password encoding to the mail servers which organizations offer through configuration plugins. Depending on its configuration, a mail server may expect usernames and passwords with characters beyond ASCII in another encoding than UTF-8. With this setting, every mailbox on such a server signs in with the encoding your organization names.
- Added the maximum pause between files of the Batch Processing Assistant to configuration plugins, so that organizations can preset or lock it, like the minimum pause.
- Improved how well the AI remembers what it looked up in a chat: for its earlier answers, it now knows which web pages it read, which searches it ran, and which sources it used. When you ask a follow-up question, it can read the page again instead of claiming that it never read it.
- Improved follow-up questions about web pages which a tool found, such as the results of a web search: the Read Web Page tool may read these pages again later in the same chat, also after you restart AI Studio and also when it may otherwise read only addresses which stand in the chat.
- Improved the texts of AI Studio: we corrected grammar mistakes, missing words, and punctuation in many English texts and improved the wording of some German ones. A few texts which every language showed in English are now translated as well.
- Improved the descriptions at the top of all assistants: long words are now hyphenated, so that the justified text shows fewer large gaps.
- Improved how AI Studio saves your settings and the projects of the Visual Briefing assistant: it now waits until the data has reached the disk before it replaces the previous version, so that a power failure while saving is far less likely to damage them.
- Improved how AI Studio saves chats: if AI Studio crashes while saving a chat, the chat keeps its previous state instead of becoming unreadable.
- Improved quitting AI Studio: no matter how you quit, AI Studio now closes your local data sources properly and stops its background server right away.
- Improved the speed of local data sources with many files: when you change, move, or remove a file, AI Studio now finds its passages right away instead of looking through every passage of the data source. Searching a data source while AI Studio indexes it got faster as well. The first time AI Studio opens a data source after the update, it prepares this once.
- Improved the assistants page: you can collapse a category with a click on its heading, and AI Studio remembers it.
- Improved the assistants page: you can hide a category you do not need with the eye next to its heading. The gear next to the heading of the page shows it again.
- Improved the "Send to ..." menu: it no longer offers the assistants of categories you hid on the assistants page. With the gear on the assistants page, you decide what happens to the assistants of hidden and collapsed categories.
- Improved the chat while you wait for an answer: AI Studio now tells you when it is processing your prompt and when the model is thinking, instead of showing an animation alone.
- Improved the chat when it nearly fills the context window of the selected model: before sending your message, AI Studio tells you and offers to compress the chat or to send your message anyway. When compressing would not help, for example, because your message alone is too long, AI Studio tells you why. For a self-hosted model, enter its context window under "Override Model Limits" in the settings of the provider.
- Improved the assistants when a request nearly fills the context window of the selected model: before sending it, AI Studio tells you, so that you can attach fewer or smaller files, or send the request anyway.
- Improved the settings of the AI tasks, which AI Studio hands to a model on its own, such as the data source selection or the text content cleaner, formerly called agents: for each of them, you can now set the minimum confidence its provider needs, and the provider selection tells you which model AI Studio uses when you choose none.
- Improved classic RAG: when the model you chose for selecting data sources or validating retrieval contexts may not see the data sources of your chat, AI Studio now uses the model of the chat for this step instead of skipping it.
- Improved the page numbers in the sources of your own documents: when a document opens without the page you clicked, AI Studio now tells you on which page the passage is and why it could not open the document there. This happens, for example, when AI Studio runs as a Flatpak, whose sandbox lets no page through, or when the program which shows the document does not allow choosing a page. In the Flatpak, the tooltip of a page number says so already.
- Improved entering API keys: AI Studio removes spaces and line breaks around a pasted key and tells you right away when a key contains a character which an API key cannot contain, such as an invisible character copied from a web page or a typographic quotation mark.
- Improved the message when a stored API key contains a character which an API key cannot contain, such as a line break: AI Studio now asks you to enter the key again instead of showing a technical error.
- Improved the API keys which organizations provide through configuration plugins: AI Studio removes spaces and line breaks around them and leaves out a key with characters which an API key cannot contain, noting this in the log.
- Improved signing in to ERI data sources: AI Studio tells you right away when a username, access token, or password contains a character which the ERI server cannot receive, such as an umlaut in a password, instead of showing a technical error. Spaces inside a password remain possible.
- Improved the ERI data sources which organizations provide through configuration plugins: AI Studio removes spaces and line breaks around their tokens and passwords and leaves out a data source whose username, token, or password contains a character which the ERI server cannot receive, noting this in the log.
- Improved the messages about failed requests to ERI servers, which no longer repeat the values sent along with a request.
- Improved the Flatpak version of AI Studio for Linux: it now runs on the GNOME 51 runtime, ships the same up-to-date version of .NET, and is built with the same up-to-date version of Rust as all other versions of AI Studio.
- Improved the Mathematics prototype: it takes more limits correctly, answers more equations within its time limit, and finds all solutions of equations with infinitely many, such as sin(x) = 1/2. The AI still gets a single value as well, such as the years in which a sum doubles.
- Improved the pause between files of the Batch Processing Assistant: a pause which your organization locks now shows a lock, like all other settings your organization manages, and a pause which your organization only presets is yours to change.
- Changed the icons of AI Studio to Lucide, an open-source icon set. All icons now share one style, and each feature shows the same icon wherever you meet it.
- Changed the names of the settings of the AI tasks in configuration plugins, which no longer speak of agents: `DataAgentDataSourceSelection` is now `DataDataSourceSelection`, `DataAgentRetrievalContextValidation` is now `DataRetrievalContextValidation`, `PreselectAgentOptions` is now `PreselectOptions`, and `PreselectedAgentProvider` is now `PreselectedProvider`. AI Studio still reads the names of v26.11.1 at least until May 2027 and names the new one in its log. Until every computer in your organization runs this version, set both names, since older versions know only the former ones.
- Changed how requests to self-hosted servers name the AI tasks, when your organization lets these requests name the feature which sent them: the User-Agent now says `Component/AI_TASK_…` instead of `Component/AGENT_…`, e.g., `Component/AI_TASK_DATA_SOURCE_SELECTION`. If you filter the logs of your servers by these names, adjust your filters.
- Changed the option `PreselectContentCleanerAgent` of the web content reader in assistant plugins to `PreselectContentCleaner`. Existing plugins need no change, because AI Studio still reads the former name.
- Fixed assistant plugins, which all appeared under "Installed Assistants" on the assistants page. Each one now appears under its own category, such as "Business", next to the built-in assistants of that category.
- Fixed the Assistant Builder, which ignored the category you chose for your assistant. You can now also name a category of your own.
- Fixed assistant plugins which wrote numbers and dates according to the region settings of your computer. Plugins now show them the same way on every computer: a decimal number such as `12.5` keeps its point, and the `DateTime` helper writes the names of months in English.
- Fixed the translation, agenda, and e-mail assistants checking your input again and again in the background, about once a second, even while you weren't typing.
- Fixed the translation assistant complaining about a missing text before you had typed anything, e.g., right after you switched the live translation on or off.
- Fixed text fields in assistants and dialogs which kept showing a missing or invalid input while you typed, until you left the field. They now check your input again half a second after you stop typing.
- Fixed AI Studio claiming that the provider had returned an invalid tool calling response when you stopped an answer while the AI was still thinking and could use tools. The same false message no longer follows a timeout or a lost connection either, which AI Studio reports on its own.
- Fixed the fonts of AI Studio, which were missing from all released versions. Your computer used fonts of its own instead; now, texts and code appear in the fonts we chose for AI Studio.
- Fixed the settings of the security audit for assistant plugins, which you could change even when your organization had locked them through a configuration plugin. They now show the lock, like all other settings your organization manages.
- Fixed the automatic security audit of assistant plugins when no model was set for it: you got two error messages for each plugin, again whenever you opened the assistants or plugins page. Now AI Studio tells you once, and the settings of the security audit show a warning.
- Fixed the AI-based data validation of classic RAG, which kept passages that the AI had judged as not fitting your question. Now the AI only gets the passages that fit. When the check fails for a passage, AI Studio keeps it, and when it fails for all of them, AI Studio tells you.
- Fixed signing in to a mailbox when your username or password contains characters beyond ASCII, such as umlauts, accents, or Asian characters. Depending on its configuration, a mail server may expect them in another encoding than UTF-8. You can now choose the encoding in the server details of the mailbox, and after a failed sign-in, AI Studio offers to test the connection once more with the encoding common in your region.
- Fixed the tiles on the assistants page, which were narrower when their texts were short, so that the tiles did not line up in columns. All tiles now have the same width, and their start buttons sit at the same height.
- Fixed the Mathematics prototype, which told the AI that a correct derivative or integral had failed its check when the values of the function were far larger than those of its derivative.
- Fixed the Mathematics prototype getting stuck for a long time when it checked a result with a very large factorial or power. Meanwhile, no other calculation could run.
- Fixed AI Studio ceasing to work when many files in a folder of a local data source changed within a short time, e.g., during a software build or while a sync tool updated the folder.
- Fixed transcripts of audio and video files which could miss whole passages. Before a transcription, AI Studio converts the file into a compact format, and it stored a few pieces of the sound in a way that many programs could not read. They then skipped up to half a minute of the recording at a time, so that the transcript lacked what was said there.
