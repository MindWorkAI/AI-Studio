# v26.11.2, build 261 (2026-11-xx xx:xx UTC)
- Added the BeyondFacts Lab as a prototype. It helps researchers prepare step by step for a challenging appearance, such as a panel discussion, an interview, or a hearing. An introduction explains how to work with the lab, and a chat tells you whether the lab fits your task. Each event gets a preparation of its own, which leads you through seven steps, from the details of the event to what you take away, and shows you which key details are still missing. In each step, a chat guides you with questions, based on your details and a guide on science in public debates. You can add material which every step takes into account, such as papers, the recording of an interview, or a poster. Your preparations are part of your data backups. To try it, open the app settings, allow preview features down to prototype, and enable the BeyondFacts Lab. Thanks to Lara Wüster from the Technical University of Munich (TUM) for the concept and the content of the lab.
- Added Lucide icons to assistant plugins: name an icon as `lucide:` followed by its name on lucide.dev, such as `lucide:house`. The names of MudBlazor icons keep working, so existing plugins need no change.
- Added a way to compress a long chat: the compress button next to the copy button in the chat toolbar lets the AI summarize the conversation, and AI Studio continues it in a new chat with the summary, your last message, and the last answer of the AI. The new chat keeps the profile, chat template, provider, tools, and data sources of your chat. Since it is much shorter, each further message costs fewer tokens, and the conversation fits models with a small context window again. Your original chat stays as it is, so you can always go back to the whole conversation.
- Added a name and a focus of your choice when you compress a chat with the compress button in the chat toolbar: you name the new chat, and you can tell the AI what its summary should pay particular attention to.
- Added the content of your documents and transcripts to the summary when you compress a chat with the compress button in the chat toolbar: the AI reads the files you attached, so the summary keeps what matters from them. For images, the summary keeps what the conversation said about them.
- Added your last message with its files to the new chat when you compress a chat with the compress button in the chat toolbar: the summary goes ahead of that message, and the files of the message stay attached to it, so the AI receives them in full.
- Added a note to the summary at the start of a chat which continues a compressed chat: it names the original chat and reminds you that the summary only describes the files attached there, so you attach a file again when the AI needs its full content.
- Added a way to send an unanswered message again when you compress a chat with the compress button in the chat toolbar: if your last message got no answer, for example because the chat had grown too long for the model, the new chat puts that message into its input field.
- Added a hint to the compress button in the chat toolbar for models which are too small for compressing a chat: compressing needs a context window of at least 8,192 tokens, so the button stays off for smaller models, and its tooltip tells you why.
- Added a notice when a chat nearly fills the context window of the selected model: once your message would take 95% of the window or more, AI Studio tells you before sending it. It offers to compress the chat when that makes enough room for your message, or to send your message anyway. For a self-hosted model, the notice needs the context window, which you enter in the expert settings of the provider.
- Improved how well the AI remembers what it looked up in a chat: for its earlier answers, it now knows which web pages it read, which searches it ran, and which sources it used. When you ask a follow-up question, it can read the page again instead of claiming that it never read it.
- Improved follow-up questions about web pages which a tool found, such as the results of a web search: the Read Web Page tool may read these pages again later in the same chat, also after you restart AI Studio and also when it may otherwise read only addresses which stand in the chat.
- Changed the icons of AI Studio to Lucide, an open-source icon set. All icons now share one style, and each feature shows the same icon wherever you meet it.
- Fixed assistant plugins which wrote numbers and dates according to the region settings of your computer. Plugins now show them the same way on every computer: a decimal number such as `12.5` keeps its point, and the `DateTime` helper writes the names of months in English.
