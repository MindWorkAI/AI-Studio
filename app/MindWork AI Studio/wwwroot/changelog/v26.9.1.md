# v26.9.1, build 256 (2026-09-xx xx:xx UTC)
- Added model-driven Web Search and Read Web Page tools for supported AI models.
- Added organization-wide management for tool availability and all Web Search and Read Web Page settings.
- Improved the safety of the Web Search and Read Web Page tools: AI Studio now removes suspicious instructions from web pages and search results before an AI model reads them, the same protection already used for files and web content you load yourself.
- Fixed the tool calling capability override in the expert provider settings, which had no effect for OpenAI providers. If you enabled tool calling for a model AI Studio does not recognize as tool-capable, that setting now works for OpenAI as it already did for the other providers.
